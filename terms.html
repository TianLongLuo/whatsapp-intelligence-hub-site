本页说明 WhatsApp Intelligence Hub 当前功能的使用边界。扩展由 TianLongLuo 维护，是独立工具，非 WhatsApp、Meta 或 Google 官方产品，与上述公司无隶属、赞助或背书关系。

1. 功能与操作范围

扩展围绕 WhatsApp Web 当前已加载的聊天，提供翻译、备份、回复建议和客户综合分析。对未加载的历史记录不作完整性保证。产品不自动发送消息。

Google Sheets 同步需要你连接自己的账号、核对并确认结果后手动执行。请在同步前检查信息内容、目标工作簿与共享权限；不要将个人表格误设为公开共享。

2. 数据权限与合规使用

仅处理你有权访问、保存、分析和同步的数据，并确保具备适当的数据处理依据。请遵守适用法律以及 WhatsApp、Google、DeepSeek 等相关服务的使用规则，尊重聊天参与者和客户的隐私。

不要利用扩展进行骚扰、欺诈、未经许可的数据收集，或其他侵害他人权益的活动。涉及敏感信息时，应先判断是否适合导出或交给外部服务处理。

3. AI 结果需要核实

翻译、客户画像、意向分析、回复和跟进建议可能存在错误、遗漏或偏差，仅作辅助参考。请对照原始聊天核实，尤其在对外沟通或作出业务决定之前。不要仅依据 AI 结果作出对他人有重大影响的决定。

4. 你自己的账号与服务费用

你需要自行管理所使用的 Google 账号、DeepSeek 服务及翻译服务配置。外部服务的访问资格、配额、价格和费用由相应服务决定，相关费用由你自行承担；本工具不提供这些服务的付费账号或额度。

本页不新增任何付费订阅、收费承诺或付费合同，也不替代你与相关服务提供方已有的约定。

5. 一个 Chrome 资料，一组账号

当前版本应在每个 Chrome 资料中仅使用一个 Google 账号和一个 WhatsApp 账号。本地数据不会自动按 Google 账号隔离，也不保证弹出任意账号选择器。多人或多账号请使用独立的 Chrome 资料，并在切换 WhatsApp 时正确更换资料来源名称。

请保护设备、本机备份和 API Key，妥善保管重要记录。卸载扩展、断开本机连接和撤销 Google 授权的作用不同，具体见隐私政策中的删除与撤销说明。

6. 本站、发布状态与既有权利

本站只提供产品与政策说明，不包含扩展源码或安装包，不授予任何源代码开源许可，也不声明已通过 Google 认证或已经全面开放。外部服务的可用性和接口变化可能影响相关功能。

本页不限制适用法律赋予你的权利，不变更你已经取得的权利，也不替代任何另行有效的约定。

7. 联系

功能、授权或条款问题，请联系维护者 TianLongLuo：公开 GitHub Issues。请勿在公开问题中提交聊天内容、客户资料、密钥或令牌。
