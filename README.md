# WhatsApp Intelligence Hub · public information site

更新日期：2026-11-12

这是面向 GitHub Pages 的三页纯静态产品与政策站点：

- `index.html`：产品说明与数据边界。
- `privacy.html`：隐私政策、Google 授权与撤销删除说明。
- `terms.html`：简短使用条款。
- `style.css`：本地样式，系统字体、响应式布局、键盘焦点、深色模式与减少动画支持。
- `.nojekyll`：按静态文件提供内容。

本站不包含扩展源码、安装包、真实聊天、客户数据、API Key、令牌或 OAuth 客户端 ID。不运行 JavaScript，不载入图片、外部字体或跟踪代码。网页内的导航和样式链接均为相对路径；唯一外部链接是下述公开联系渠道。

## 公开联系渠道

[GitHub Issues](https://github.com/TianLongLuo/whatsapp-intelligence-hub-site/issues)

只提交不含敏感数据的问题描述，不要公开聊天、客户信息、API Key、令牌或其他凭证。

## 本地预览

在本站目录启动任意静态文件服务器，并打开 `index.html`。无需构建、依赖安装、后端或账号。站点不应放入任何扩展源码、安装包或私密数据。
