隐私政策

了解信息在什么位置保存、何时发送，以及如何撤销或删除。

更新日期：2026-11-12

本政策说明由 TianLongLuo 维护的 WhatsApp Intelligence Hub 扩展当前的数据处理方式。本网站仅提供产品与政策说明，不运行扩展、不接收聊天内容，也不使用跟踪脚本。扩展是独立工具，非 WhatsApp、Meta 或 Google 官方产品。

1. 处理哪些信息，以及为什么

扩展读取 WhatsApp Web 页面中当前已加载的聊天信息，以提供翻译、备份、回复建议、专项分析和客户综合档案。信息可能包括消息正文、时间、联系人显示名称、电话号码、来源消息标识，以及你确认的客户画像、需求、标签、意向和跟进建议。

综合分析使用你当前选择的范围，不自动分析未加载的全部聊天历史。产品不自动发送消息。使用前，请确认你有适当的数据访问和处理依据。

8.0 新「客户」工作区默认不采集聊天正文；只有你明确加入客户跟进并确认范围后，才采集该聊天已加载的最近消息（默认50条，可选1–200条）。首次加入立即分析；后续有新内容并静默满设定时长后批量分析。后台补漏只使用已授权的本机有限缓存，不打开未加入的聊天。新CRM隐私开关不改变旧备份、翻译、回复和手动分析的原有行为。

新CRM区分销售阶段、当前意向和客户质量。普通更新自动生效；成交、降级、跳级、风险、人工锁定冲突等整批进入待处理，48小时后仍保持原值并提醒。人工修改会锁定字段；AI原始建议、人工最终值、变更历史、有限消息缓存和跟进任务保存在本机。

新页面需明确确认资料来源，来源名称不是系统自动验证的WhatsApp登录账号。暂停或移出会停止新采集、分析及后续同步请求；已经发出的请求和已到达服务方的数据不能撤回。发送前会对可识别的密钥、密码、银行/证件号码等模式打码，但规则检测不能保证识别所有敏感信息。媒体只记录类型和文件名，不下载或推测内容。

2. 信息保存在什么位置

设置、API Key、聊天备份、分析结果、登记的 CRM 表格标识及同步状态保存在当前 Chrome 资料的扩展本地存储中。API Key 在该存储中不是加密保险箱，应保护设备和 Chrome 资料的访问权限。

导出的备份另存为本机文件，由你管理。卸载扩展不会自动删除这些导出文件。本版没有发布者运营的客户数据接收服务器或遥测接口。

同一 Chrome 资料内的本地数据不自动按 Google 账号分隔。本版建议每个 Chrome 资料仅使用一个 Google 账号和一个 WhatsApp 账号；多人或多账号请使用独立 Chrome 资料，切换 WhatsApp 时应正确更换资料来源名称。

3. 何时发送给外部服务

DeepSeek

当你使用 AI 翻译、回复建议或分析时，扩展将对应选定的文本、提示及必要上下文发送到你配置的 DeepSeek 服务。新CRM同时发送脱敏后的当前客户档案、锁定字段和人工备注作为必要上下文；这些字段可能包含从启用的V2表格同步回来的修订，不会发送整个工作簿或其他客户记录。请在操作前确认所选信息适合交由该服务处理。

Google Cloud Translation

当你使用 Google 翻译时，扩展发送待翻译文本和语言参数，使用你自己配置的翻译 API Key。

Google Sheets

旧版在你核对确认并手动同步后；新CRM在你明确创建/升级V2并启用结构化同步后，扩展向你自己的 CRM 工作簿发送客户摘要、标签、意向依据、跟进任务，以及来源消息标识、数量和时间等结构化信息。默认不向 Sheets 同步完整原始聊天。

扩展会读取登记工作簿的结构与已有相关记录，用于校验、去重和更新。工作簿保存于你自己的 Google 账号，访问与共享由你管理。

Google 和 DeepSeek 对其接收数据的处理适用各自的服务条款与隐私政策。扩展不提供这些服务的账号或计费额度；相关费用由你自行承担。

4. Google 授权与 Limited Use

扩展唯一的 Google OAuth 范围为 https://www.googleapis.com/auth/drive.file。该范围允许查看、编辑、创建和删除你通过本应用使用的指定文件，不是读取整个 Google Drive 的授权。扩展当前提供创建、读取、校验和写入 CRM 工作簿的功能，不提供删除云端文件的操作。

授权对象是你自己的 Google 账号。OAuth 令牌由 Chrome 身份 API 管理，不写入扩展的业务本地存储，不交给 WhatsApp 内容脚本，也不发送给发布者。

WhatsApp Intelligence Hub 对通过 Google API 获得的信息的使用和转移，遵守 Google API Services User Data Policy，包括 Limited Use 要求。这些信息仅用于你选择的 CRM 功能，不用于广告、不出售，也不用于训练通用 AI 模型。Google OAuth令牌不会发送到模型服务。启用新CRM分析后，与该客户相关的当前档案和人工备注可能作为必要上下文发送给DeepSeek，不读取并发送整份工作簿。

发布者不通过本扩展投放基于用户数据的广告、出售用户数据，或使用用户数据训练通用 AI 模型。你主动调用的外部服务如何处理所接收数据，受相应服务政策约束。

5. 如何撤销连接、删除信息

  • 停止新CRM：在客户工作区暂停或移出，可选择删除该客户的新CRM本机历史，不删除旧备份及云端表格。
  • 断开本机连接：扩展中的这一操作会保留云端表格和本机登记，不等于在 Google 端撤销授权。
  • 撤销 Google 授权：前往 Google 账号的「第三方应用和服务连接」管理，撤销本应用的访问权限。
  • 删除云端表格：在你自己的 Google Drive 中手动删除；撤销授权或卸载扩展不会自动删除表格。
  • 删除本机数据：卸载扩展会移除当前 Chrome 资料中的扩展本地存储。请先备份需要保留的记录。已经导出的备份文件需另外手动删除。

以上操作的作用范围不同。请分别检查 Chrome 本地数据、导出文件和 Google Drive 中的表格。
